# 기술 설명

## 디스크

트랙 01은 MODE1/2352 ISO9660입니다. `tools/cdimg.py`가 섹터 헤더·EDC/ECC를 다시 계산하며 파일을 제자리에 덮어씁니다. v1.0에서는 모든 파일이 원래 섹터 수 안에 들어가 디스크 크기가 원본과 같습니다. 음악 트랙 02~14는 건드리지 않습니다.

## 압축

게임 데이터는 허프만 트리 기반 LZ 압축(`tools/lz.py`)을 씁니다. 압축 묶음은 `0x0C` 명령(원본 주소 → 대상 주소)의 나열이고, 트리가 두 가지입니다.

- 미션 팩(`DIR00/*`, `DIR03/*`): `BANK00.BIN` 0x1122C(RAM 0x0603122C)의 4096바이트 트리. `tools/extract.py`가 `tree.bin`으로 꺼냅니다.
- `DIR01` 팩과 `BANK00.BIN` 안의 도움말 맵: `BANK00.BIN` 0x5878(RAM 0x06025878)의 타이틀 트리.

다시 압축한 덩어리가 원래 자리보다 크면 파일 끝에 붙이고 `0x0C` 명령의 원본 주소를 고칩니다(`build.patch_chunk`).

## 미션 대사

미션 팩마다 대사 줄 그림 영역이 있고, 한 줄은 168×16 픽셀의 4bpp 그림(0x150바이트)입니다. 원본 줄 그림의 MD5 앞 8자리(`sheets/order.json`)로 번역 줄(`tr/DIR0x_xx.txt`)과 연결하고, 갈무리11로 다시 그려 같은 자리에 넣은 뒤 팩을 다시 압축합니다(`tools/render.py`, `tools/dlg.py`).

## 배경 그림(BG) 글자

`DIR04/BG/*.BG`는 [팔레트 0x800바이트][16×16 8bpp 블록 0x100바이트씩][블록 번호 맵(16비트, 값 = 블록 번호×2)] 구조입니다. 글자 영역을 화면 맵으로 펼쳐 줄 단위로 찾은 뒤(`tools/bgtext.py`), 한글로 다시 그려 블록을 다시 만들고 맵을 고칩니다(`tools/bgk.py`).

| 파일 | 맵 위치·폭 | 내용 |
| --- | --- | --- |
| `S1~S7.TXT` | 자체 형식(`tools/story.py`) | 스토리 화면 7장 |
| `MISSION.BG` | 0x16800, 34 | 미션 목표 |
| `BACKUP.BG` | 0x3C800, 40 | 저장·백업 메시지 28줄 |
| `SETTING.BG` | 0x39800, 40 | 「사용할 기체를 선택해 주십시오」(빈 블록 1810~1822 사용) |
| `ENDSTORY.BG` | 0x3F000−42, 40 | 엔딩 뉴스 기사 16줄 |
| `DEMO.BG` | 0x1790A, 19 | 오프닝 연표(1비트, 오른쪽 정렬) |
| `END1.BG` | 0xE4E6, 40 | 엔딩곡 제목·크레디트 |

## 일시정지 도움말

도움말 문장은 `BANK00.BIN`(RAM 0x06020000) 안에 압축된 NBG3 맵 18개로 들어 있고, 각각 `0x0C` 명령이 VDP2 0x25E3EB80으로 풉니다. 글자 타일은 `DIR01_0.BIN`의 압축 덩어리(명령 0x184, VRAM 0x29000 = 문자 0x1480부터)입니다. 갈무리11로 문장을 그려 8×8 타일로 쪼개고 중복을 합친 뒤, 타일 묶음과 맵 18개를 함께 다시 만듭니다(`tools/helpk.py`, 타일 511칸 중 509칸 사용).

## 스프라이트 글자

- `SPRITE/BACKUP.SPR`: 0x6BA8부터 184×11 8bpp 스프라이트 2개(값 2) — 디스크 선택·데이터 삭제 문구. 갈무리9.
- `SPRITE/SETTING.SPR`: 0x59700+14행부터 64×11 8bpp 띠(값 4)가 이어진 리본에 세팅 화면 안내 메시지 17종이 가로로 이어져 있습니다. 리본을 펼쳐 각 메시지의 원래 x 구간(`tr/setspr.txt`의 앞 두 칸) 안에 갈무리11로 다시 그립니다. 구간 밖의 점 표시는 원본 그대로 둡니다.

## 조사 범위

- 모든 디스크 파일에서 Shift-JIS 문자열을 찾았지만, 화면에 나오는 문자열은 없었습니다(`tools/sjscan.py`). 글자는 모두 그림입니다. `GAME_ABS.TXT` 등 디스크 정보 파일은 게임에서 표시되지 않아 손대지 않았습니다.
- BG 23개와 스프라이트 9개를 펼쳐 확인했습니다(`tools/bgr.py`, `tools/sprv.py`). 결과·스태프·타이틀 화면 등은 영어입니다.
- `END2.BG`의 엔딩곡 가사와 `MOVIES/*.CPK`(Cinepak 동영상) 속 글자는 손대지 않았습니다.

## 테스트 도구

`tools/emu.py`는 Ymir 에뮬레이터 코어로 만든 작은 테스트 프로그램(`tools/gverify.cpp`)을 백그라운드로 띄워 입력을 보내고 화면·VRAM을 덤프하는 개인 테스트용 도구입니다. `tools/v1sprites.py`는 VDP1 VRAM 덤프의 스프라이트를 그림으로 꺼냅니다.
